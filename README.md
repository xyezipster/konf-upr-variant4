# Эмулятор оболочки, вариант 4

Практическая работа № 1 по дисциплине «Конфигурационное управление».
Группа ИКБО-62-25. Автор: xyezipster.

Этап 1: консольный REPL, имя VFS в приглашении, кавычки,
переменные окружения, заглушки ls и cd, команда exit.

## Запуск и тесты

Требуется Python 3.10+. Зависимостей и отдельной сборки нет.

```sh
./run.sh
python3 -B -m unittest discover -s tests -v
```

`ls [пути...]` и `cd [путь]` выводят своё имя и аргументы.
`exit` завершает программу. Неизвестные команды и ошибки ввода
выводятся в консоль. Парсер раскрывает `$NAME` и `${NAME}`;
одиночные кавычки и обратная косая черта сохраняют буквальный текст.

Пример ручного ввода:

```text
ls "$HOME"
cd "my dir"
unknown
exit
```

## Этап 2: настройки

`--vfs PATH` задаёт имя VFS (загрузка появится на этапе 3).
`--log PATH` включает JSON-журнал с именем пользователя.
`--startup PATH` запускает файл команд UTF-8, `#` начинает комментарий.
Все параметры необязательны и выводятся при запуске.
Ошибки скрипта содержат путь и номер строки; следующие команды
продолжают выполняться. `exit` завершает весь эмулятор.

```sh
./scripts/demo_config.sh
./scripts/demo_errors.sh
```

## Этап 3: виртуальная файловая система

`--vfs` загружает JSON со списком `entries`. Каждый узел содержит
абсолютный `path`, `type` (`dir` или `file`) и `mode` из трёх
восьмеричных цифр. Файл содержит `encoding: base64` и `data`.
Все родительские каталоги нужно перечислить, включая `/`.
Без `--vfs` программа создаёт пустой корень в памяти.

```sh
./scripts/demo_vfs.sh
./scripts/demo_vfs_errors.sh
```

Исходный JSON программа только читает. Архивы и двоичные файлы
в репозиторий не добавляются: пример двоичных данных хранится в JSON.
