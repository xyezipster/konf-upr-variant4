## Запуск

Нужен Python 3.10+. Дополнительных библиотек и сборки нет.
Команды выполняются из папки проекта.

```sh
python3 -B -m src
```

```sh
python3 -B -m src --log logs/session.json --startup scripts/stage2.txt
```

## Параметры

| Параметр | Назначение |
| --- | --- |
| `--vfs PATH` | Путь к VFS |
| `--log PATH` | JSON-журнал команд |
| `--startup PATH` | Стартовый скрипт UTF-8 |
| `--help` | Справка |

Все параметры необязательны и выводятся при запуске.
Стартовый скрипт выполняет команды по строкам и показывает ввод и вывод.
При ошибке сообщает номер строки и продолжает выполнение.
`exit` завершает программу. В журнал попадают вызовы команд,
результаты, ошибки, время и имя пользователя ОС.

На этом этапе `--vfs` задаёт имя VFS в приглашении;
файл ещё не загружается. Без пути используется `MyVFS`.

Парсер поддерживает кавычки, `$NAME` и `${NAME}` из окружения ОС.
Одиночные кавычки запрещают раскрытие переменных. `#` в начале строки
или после пробела начинает комментарий. Ошибки выводятся в консоль.
Приглашение содержит имя VFS и текущий каталог.

## Команды

| Команда | Действие |
| --- | --- |
| `ls [пути...]` | Заглушка: выводит имя и аргументы |
| `cd [путь]` | Заглушка: выводит имя и не более одного аргумента |
| `exit` | Завершение программы |

Пример ручного ввода:

```text
ls "$HOME"
cd "my dir"
unknown
exit
```
