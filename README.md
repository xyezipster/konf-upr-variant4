## Запуск

Нужен Python 3.10+. Дополнительных библиотек и сборки нет.
Команды выполняются из папки проекта.

```sh
python3 -B -m src
```

```sh
python3 -B -m src --vfs data/demo.json --log logs/session.json --startup scripts/stage4.txt
```

## Параметры

| Параметр | Назначение |
| --- | --- |
| `--vfs PATH` | Путь к VFS |
| `--log PATH` | JSON-журнал команд |
| `--startup PATH` | Стартовый скрипт UTF-8 |
| `--help` | Справка |

Все параметры необязательны и выводятся при запуске.
Стартовый скрипт выполняет команды по строкам и показывает ввод и вывод.
При ошибке сообщает номер строки и продолжает выполнение.
`exit` завершает программу. В журнал попадают вызовы команд,
результаты, ошибки, время и имя пользователя ОС.

Парсер поддерживает кавычки, `$NAME` и `${NAME}` из окружения ОС.
Одиночные кавычки запрещают раскрытие переменных. `#` в начале строки
или после пробела начинает комментарий. Ошибки выводятся в консоль.
Приглашение содержит имя VFS и текущий каталог.

## Команды

| Команда | Действие |
| --- | --- |
| `ls [-al] [пути...]` | Список файлов; `-a` включает скрытые, `-l` показывает права и размер |
| `cd [путь]` | Переход в каталог; без пути в `/` |
| `whoami` | Имя пользователя ОС |
| `cal [год]` | Текущий месяц или заданный год |
| `cal месяц год` | Заданный месяц |
| `du [-s] [пути...]` | Размер в байтах; `-s` выводит только итоги |
| `exit` | Завершение программы |

Пути поддерживают `.` и `..`. `du` считает байты содержимого файлов.

```text
ls -al
cd /home/student/docs
ls
cd /
whoami
cal 2 2024
du -s /
exit
```

## VFS

VFS загружается из JSON в память. Без `--vfs` создаётся пустой корень.
Вложенность задаётся абсолютными путями, родительские каталоги
перечисляются явно. Пример:

```json
{
  "entries": [
    {"path": "/", "type": "dir", "mode": "755"},
    {
      "path": "/hello.txt",
      "type": "file",
      "mode": "644",
      "encoding": "base64",
      "data": "SGVsbG8hCg=="
    }
  ]
}
```

Файлы хранятся в base64. Если `mode` не задан, каталог получает `755`,
файл `644`. Исходный JSON программа только читает.
В `data/` есть минимальная VFS, несколько файлов, три уровня
каталогов и файл с неверным форматом для проверки ошибок.
